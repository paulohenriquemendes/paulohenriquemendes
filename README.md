# Bem-vindo ao meu perfil do GitHub

Sou **desenvolvedor full stack** com experiência na construção de soluções web e mobile, atuando desde a concepção da interface até a estrutura de back-end e dados.

Ao longo da minha trajetória, trabalhei com diferentes tecnologias e contextos, combinando desenvolvimento, design de interfaces e ensino em tecnologia. Tenho uma atuação versátil, com experiência em **React**, **Angular**, **Node.js**, **Java**, **Spring Boot**, **Ionic**, bancos de dados relacionais e NoSQL, além de uma base sólida em **UI/UX Design** com Figma.

Busco desenvolver produtos digitais que conciliem clareza visual, boa experiência de uso, estrutura técnica consistente e aderência às necessidades reais de cada projeto.

- 💼 Atuação em desenvolvimento, docência em tecnologia e projetos freelancer
- 🧠 Experiência com front-end, back-end, APIs, bancos de dados, prototipação e produtos digitais
- 🚀 Interesse contínuo em evolução técnica, arquitetura de aplicações e experiências digitais bem construídas
